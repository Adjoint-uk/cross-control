What's in the box

Built like infrastructure, not a desk toy.

TRANSPORT

QUIC, not TCP

Multiplexed streams, built-in TLS 1.3, and 0-RTT reconnection after a network blip. Control, input, and clipboard ride their own lanes.

WAYLAND

Native from day one

Input via evdev/uinput, so it works on Wayland where Barrier and Input Leap fall over — with enhanced support for wlroots compositors.

DISCOVERY

Zero-config mDNS

Machines find each other on the LAN automatically. No static IP in a config file — the advert even carries the cert fingerprint to pin.

SECURITY

Trust on first use

SSH-style certificate pinning. No central authority, no account, no cloud. Keys stay on your machines; traffic is always encrypted.

CLIPBOARD

Text, HTML & images

Your clipboard follows control across the seam — plain text, rich HTML, and PNG images, synced on hand-off with a configurable size cap.

TOPOLOGY

Many machines, many monitors

Star topology across any number of boxes, multi-monitor per machine, and edge-based switching just like macOS Universal Control.

No second computer? No problem

Run the whole thing on one machine.

The loopback example spins up two daemons on 127.0.0.1 and drives a real session end to end — handshake, cursor crossing, input forwarding — no hardware, no root, no display server.

loopback demo
$ cargo run -p cross-control-daemon \
    --example loopback

Install

One command on each machine.

The script grabs the latest release binary and checks your input permissions. Then generate a cert, drop a small config, and cross-control start.

  • Linux, x86_64 or aarch64 — Windows & macOS planned
  • Your user in the input group
  • /dev/uinput readable for virtual devices
  • Optional: systemctl --user enable --now cross-control
install.sh
# on both machines
$ curl -fsSL https://raw.githubusercontent.com\
/Adjoint-uk/cross-control/main/install.sh | bash

$ cross-control generate-cert
$ cross-control start
# move your cursor to the edge →
